# Algorithm

Semantics is the scientific and philosophical study of meaning in language. \
Semantics is the main what we focus on this lesson. \
Mainly it wondering how words and sentences convey ideas, \
how meanings forms expressions, 
and where language are representing a real world.


We need math for this conversions: words "dog" and "puppy" are related, \
so that "king" and "queen" share a relational structure (semantics right!)

Lets formulate the goal: we know the word often called center word and we know the context \
we need to predict the next word based on these.

For example, we have given center wrod $w$ and vectors for this: \
$v_w\in\mathbb{R}^d$ и выходной $u_c\in\mathbb{R}^d$ (context).

The probability of observing context word $c$ \
given center word $w$ is:

$$P(c\mid w)=\frac{\exp(u_c^\top v_w)}{\sum_{c'\in V}\exp(u_{c'}^\top v_w)}.$$
where $V$ is the vocabulary size (32,000 or more).


But if carefully look at the denominator we realize that calculatign of it \
requires to compute the dot product for every word in the V \
for every training step, which is computationally $O(V)$ and way too slow.


To solve this we would use sigmoid, negative ng and positive pos samples.

## Algorithm

```py
import numpy as np

corpus = ["the cat sat on the mat", "the dog sat on the log", "cats and dogs are pets"]
words = list(set(" ".join(corpus).split()))
vocab_size = len(words)
word2idx = {w: i for i, w in enumerate(words)}


d = 5      # d - dimention of the words in V
ws = 2    # we only watch for 2 words: 2w <- c -> 2w
ng_samples = 2
lr = 0.1 # learning rate
epocks = 1000

np.random.seed(42)
V = np.random.randn(vocab_size, d) * 0.1
U = np.random.randn(vocab_size, d) * 0.1

def sigmoid(x):
    return 1 / (1 + np.exp(-x))


def generate_pairs(corpus, window_size):
    pairs = []

    for sentence in corpus:
        indices = [word2idx[w] for w in sentence.split()]

        for center_pos, center_word in enumerate(indices):
            start = max(0, center_pos - window_size)
            end = min(len(indices), center_pos + window_size + 1)

            for context_pos in range(start, end):
                if context_pos == center_pos: continue
                pairs.append((center_word, indices[context_pos]))
    return pairs

training_pairs = generate_pairs(corpus, ws)

for epock in range(epocks):
    total_loss = 0
    
    np.random.shuffle(training_pairs)
    
    for center_idx, context_idx in training_pairs:
        v_center = V[center_idx] 
        u_context = U[context_idx]
        
        ng_indices = np.random.choice(vocab_size, size=ng_samples, replace=False)
        u_ng = U[ng_indices]
        
        z_pos = np.dot(v_center, u_context)
        p_pos = sigmoid(z_pos)
        
        z_ng = np.dot(u_ng, v_center)
        p_ng = sigmoid(-z_ng)
        
        loss = -np.log(p_pos + 1e-10) - np.sum(np.log(p_ng + 1e-10))
        total_loss += loss
        
        grad_pos = (p_pos - 1.0) * u_context 
        
        grad_ng = np.dot((p_ng - 1.0), u_ng) 
        
        grad_v = grad_pos + grad_ng
        
        grad_u_context = (p_pos - 1.0) * v_center
        grad_u_ng = np.outer((p_ng - 1.0), v_center)
        
        V[center_idx] -= lr * grad_v
        U[context_idx] -= lr * grad_u_context
        U[ng_indices] -= lr * grad_u_ng

    if epock % 200 == 0:
        print(f"epock {epock}, Loss: {total_loss:.4f}")


embeddings = V 

def cosine_sim(w1, w2):
    v1, v2 = embeddings[word2idx[w1]], embeddings[word2idx[w2]]
    return np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2))

print("\n")
print("'cat' and 'dog':", cosine_sim('cat', 'dog'))

print("\n")
print("'cat' and 'log':", cosine_sim('cat', 'log'))

```
